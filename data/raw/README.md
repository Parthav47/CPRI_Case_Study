The original CPRI/PowerNext AI challenge dataset is intentionally not included
in this public repository. It was provided for the challenge and is omitted
to respect its distribution and usage restrictions.

To reproduce the pipeline, place the authorized dataset at:

data/raw/CPRI_Hackathon_Screening_Dataset_PARTICIPANT.xlsx

The repository contains the feature-engineering, modeling, prediction, evaluation,
and automation code without redistributing the source dataset.
