# CPRI Hackathon

A structured workspace for dataset forensics, baseline modeling, feature engineering, tuning, and final model development.

## Project layout

- `data/raw/`: source datasets
- `data/processed/`: cleaned and transformed datasets
- `notebooks/`: analysis and modeling workflow
- `src/`: reusable project code
- `reports/`: findings and written outputs
- `submissions/`: final competition artifacts

## Getting started

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Place the supplied workbook at `data/raw/CPRI_Hackathon_Screening_Dataset_PARTICIPANT.xlsx`.
4. Run the notebooks in numerical order.
